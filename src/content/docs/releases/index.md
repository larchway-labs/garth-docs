---
title: Release notes
description: What changed in each version of Garth, newest first. A page is added here with every release.
---

Garth is versioned 0.0.N, and each release adds one to the last number. To see which version an install runs, look at Admin → System. Garth’s Documentation page links to the notes for the version it runs.

Each release has a page of its own, listed in the sidebar with the newest first. A note says what changed for the people using Garth and for the people running it, under **New**, **Changed** and **Fixed**.
