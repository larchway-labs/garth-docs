title: Garth 0.0.1
description: "November 11, 2026. The first numbered release: Garth knows its own version, sessions save their work before they are ended for age, and sandboxes can reach the attached Toft installs."
---

## New

- **Garth has a version.** It is 0.0.1, and each release adds one to the last number. Admin → System shows the version and the commit it was built from.
- **Sandboxes reach the Toft installs Garth is attached to**, and the apps on them, so the agent can deploy and check what it deployed.

## Changed

- **A session that reaches the age limit saves its work first.** A running session commits what is unsaved before it ends. A paused session past the limit is ended too, and keeps its unpushed work.
- **End session is on the paused-session page**, so a paused session can be ended without resuming it.
- **Fewer settings.** Settings that Garth can work out or keep for itself are gone.
