title: Garth 0.0.5
description: "November 11, 2026. Policies becomes Settings, and administrators set the size of the warm pool of ready sandboxes."
---

## New

- **Set the warm pool's size** on Admin → Settings, from 0 to 10 idle sandboxes. The size takes effect at once, and Garth puts it back if the cluster's setting drifts.
- **Admin → Sandbox lists the idle sandboxes**, the image each one runs, and which ones are being replaced.

## Changed

- **Policies is now Settings**, at the top of the admin menu beside Overview. It has a Sandbox section, and links to the settings that are kept as lists: Models, Sign-in, Toft installs, Trusted sources, Git hosts, and Email and Slack. The old address redirects.
- **The warm pool keeps its sandboxes when the session image changes.** Garth replaces sandboxes made from an older image one a minute, and never touches one that is in use.
