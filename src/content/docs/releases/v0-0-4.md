## New

- **The same toolchains as Toft.** The session's sandbox runs Debian trixie, as Toft's runners do. Each language Toft deploys is installed at the version an app gets when it doesn't pin one:
  - Python 3.15, with uv and pip
  - Node 26, with npm, pnpm and yarn
  - Go 1.27
  - R 4.6.2, with renv and packages from p3m.dev

  There is also a C toolchain, the usual development libraries, and sqlite3, fd, tree, wget and zip. The agent is told what's installed, and to install dependencies into the project. Snapshots leave dependency folders out.
- **Delete an ended session.** This removes its record and transcript; its usage is kept. You can delete its branch too. Whoever may end a session may delete it.

## Changed

- **Spend still names deleted projects.** A deleted project's name and owner (a person or a group) are kept, so cost breakdowns keep naming it. Project rows show their owner, and a deleted project is marked as deleted and has no link.
- **More package sources are allowed by default:** p3m.dev and the Yarn registry are on the default network allow list.
