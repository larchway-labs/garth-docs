## New

- **End a session from the project page.** End session is next to Resume your session, and on each live row of the project's sessions. It's there for whoever may end the session: the person whose session it is, the project's owner, or an administrator. Before, a session whose page wouldn't open could only be ended by an administrator.

## Fixed

- **Commits made in the terminal show up in Changes.** The Changes panel used to read git only when the session started and after each agent turn, so a terminal commit didn't appear and Commit and push stayed off. Garth now watches git and updates the panel when anything changes. Opening Changes also reads git again.
